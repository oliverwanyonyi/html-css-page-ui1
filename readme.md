# ORYN Landing Page

A simple landing page concept for ORYN, an AI-powered workflow automation platform.

## Features

- Responsive-ready navigation and hero section
- Light/dark theme toggle that remembers your choice

## Run

Open `index.html` in a web browser. No installation or build step is required.

## Project files

- `index.html` — page structure
- `css/style.css` — styling and themes
- `js/script.js` — theme toggle behavior
